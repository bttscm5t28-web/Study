# 一 · ONE

一支 66 秒的品牌态度短片。主题取自《道德经》：**道生一，一生二，二生三，三生万物。**
画面是扁平的包豪斯风格，只用一张纸、一支墨，外加红、蓝、黄三种原色。配乐是原创曲，每个声音都用代码合成，画面逐拍对齐鼓点。

- 成片：[`output/one.mp4`](output/one.mp4)（1920×1080 · 60fps · H.264 + AAC 立体声）

## 结构

| 时间 | 章节 | 画面 | 音乐 |
| --- | --- | --- | --- |
| 00:00 | 01 道生一 · ORIGIN | 十字细线从四边汇聚，交点处诞生一个红点 | 铺底渐起，第一声拨弦 |
| 00:08 | 02 一生二 · DUALITY | 红点拉成一笔“一”，再分成两笔“二”，最后变成一红一墨两个圆 | 底鼓、低音进入 |
| 00:16 | 03 二生三 · TRINITY | 康定斯基的蓝圆、红方、黄三角，逐拍跳动后展开成三条色带 | 四拍律动、踩镲、拍手 |
| 00:24 | 04 三生万物 · MULTITUDE | 网格里的形状铺满画面，越变越快，最后坍缩回一个红点 | 军鼓滚奏 + 噪声上升 |
| 00:32 | 05 万物 · EVERYTHING | 八张卡，每小节一切：形 律 衡 空 色 动 简 一 | 高潮：全编制 + 琶音 + 侧链 |
| 00:48 | 06 归一 · RETURN | 万物四散，一笔画圆，然后全部回到红点 | 鼓组撤出，只剩心跳 |
| 00:56 | 07 至简 · SIMPLICITY | 红点铺满全屏：“大道至简”。之后收成标志 ●NE，红点就是 O | 冲击，收在 Cmaj9 钟声和弦上 |

## 设计语言

- **色彩**：纸 `#EEEAE2` · 墨 `#151515` · 朱红 `#E2432A` · 钴蓝 `#2747A6` · 铬黄 `#F1B530`
- **字体**：标题用思源宋体 Bold，巨型单字用思源黑体 Black，英文用 Inter / Inter Display
- **形状**：圆、方、三角都按等面积的极坐标轮廓采样，任意两种之间都能平滑变形
- **节奏**：120 BPM，一拍 0.5 s，一小节 2 s。画面里所有跳动、旋转、切换都落在拍点上；HUD 右下角的四格节拍器实时显示当前拍
- **HUD**：四角的片名、章节、时间码会采样背景亮度，自动在墨色和纸色之间切换

## 制作

| 文件 | 作用 |
| --- | --- |
| `music.py` | 用纯 numpy 合成配乐：加法锯齿铺底、FM 玻璃拨弦、合成底鼓 / 拍手 / 踩镲 / 军鼓、扫频噪声、卷积混响、底鼓侧链、母带处理 |
| `film.html` | Canvas 动画，`render(t)` 按时间确定性地画出任意一帧 |
| `render.js` | 用无头 Chromium（Playwright）4 路并行逐帧截图，直接管道送进 ffmpeg 编码 |
| `build.sh` | 一键成片 |

```bash
pip install numpy
./build.sh            # 约 5 分钟（4 核）
node render.js preview 2.5 33 60.5   # 只渲染几张静帧预览 → build/preview/
```
